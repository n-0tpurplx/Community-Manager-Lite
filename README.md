# Community Manager Lite

A VERY lightweight ERLC management dashboard built for a single community.

## Status

Current Version: v0.1

Development Stage: Documentation & Planning

This project is currently in the planning phase. No functionality has been implemented yet.

## About

Community Manager Lite aims to provide a simple web dashboard for authorized staff members to manage an ERLC server through a secure interface.

The project is intended to be a lightweight alternative focused on the needs of a single community rather than supporting multiple servers.

## Planned Features
